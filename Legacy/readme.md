# Download Cleaner

A Python-based Downloads folder cleanup tool with both a command-line interface (**CLI**) and a graphical user interface (**GUI**).

Download Cleaner can organize files, find large files, identify old archives/installers, detect duplicate files, and remember files that should never be asked about again.

---

## Features

* Organize files by category
* Choose where each category should be stored
* Save category destinations as permanent defaults
* Leave a category in the Downloads folder
* Detect duplicate files using `SHA-256`
* Find large files above a configurable size
* Find old archives/installers above a configurable age
* Select files for deletion before anything is removed
* Permanently ignore selected files
* Scan files inside organized subfolders
* View current configuration/settings
* Use the same configuration from both CLI and GUI

---

* **Python 3.x**
* **questionary**
* **Tkinter**

## Configuration

Changes to `config.json` are shared by both the CLI and GUI. Both use the same `config.json` file located in the project root.

Example:

```json
{
  "downloads_path": "AUTO",
  "large_file_mb": 1024,
  "old_archive_days": 15
}
```

### Downloads Path

```json
"downloads_path": "AUTO"
```

`AUTO` uses the current user's Downloads folder.

A specific folder can also be configured:

```json
"downloads_path": "C:\\Users\\YourName\\Downloads"
```

### Large File Limit

```json
"large_file_mb": 1024
```

This controls the minimum size reported by the large-file scanner.

For example, to check files that are 50 MB or larger:

```json
"large_file_mb": 50
```

### Old File Age

```json
"old_archive_days": 15
```

This controls the age threshold used by the old-file cleanup.

---

## Archive / Installer Extensions

The `archive_extensions` setting controls which extensions are checked by the old-file cleanup.

Example:

```json
"archive_extensions": [
  ".zip",
  ".rar",
  ".7z",
  ".tar",
  ".gz",
  ".tgz",
  ".exe",
  ".msi"
]
```

---

## Categories

Files are grouped into categories based on their extensions.

Example:

```json
"categories": {
  "Documents": [".pdf", ".doc", ".docx"],
  "Images": [".jpg", ".png"],
  "Videos": [".mp4", ".mkv"],
  "Audio": [".mp3", ".wav"],
  "Archives": [".zip", ".rar"],
  "Installers": [".exe", ".msi"]
}
```

---

## Choosing Category Locations

When a category has not been configured yet, Download Cleaner asks where the files should go.

You can choose:
* **Main folder** — use the category name as the folder
* **Custom folder name** — choose your own folder
* **Leave in Downloads** — do not move that category

A custom folder can either be placed inside the category folder or directly in Downloads.

For example:

```text
Downloads/
└── Videos/
    └── Movies/
        └── movie.mp4
```

or:

```text
Downloads/
└── Videos/
    └── movie.mp4
```

The selected destination can be saved as the permanent default for that category.

---

## Duplicate Detection

When organizing files, Download Cleaner checks for an existing file with the same name.
If an identical file already exists, the program compares the files using `SHA-256`.
Identical files can then be selected for deletion.

---

## Old File Cleanup

The old-file cleanup scans the Downloads folder and its subfolders for configured archive/installer extensions.
Files meeting the configured age threshold are shown for review before deletion.
Nothing is deleted without user confirmation.

You can:
* Select files to delete
* Skip the cleanup
* Select files to permanently ignore

---

## Ignore List

Files selected as **Never ask again** are stored in `config.json`.
The file's `SHA-256` hash is used as the identifier.
This allows the application to recognize the same file even if its name changes.
Ignored files are excluded from future cleanup reviews.

---

## Safety

> [!WARNING]
> Download Cleaner does not automatically delete files simply because they match a rule.
> Files selected for deletion are presented for confirmation before they are removed.
> Use the configuration settings carefully, especially when adding extensions such as `.exe` or `.msi` to the old-file cleanup list.

---

## Notes

* `__pycache__` folders are generated by Python and do not need to be kept as part of the project.
* Files inside `old versions/` are historical copies and are not required to run the current application.
* Keep the main `config.json` in the project root.
